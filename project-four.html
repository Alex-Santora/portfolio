Academic Project

Plant Watering System

An automated system that monitors soil moisture and activates a water pump when a plant needs water, so care happens on a calibrated threshold rather than by hand.

Overview

A small embedded build that pairs a soil-moisture sensor with pump control to keep a plant watered without manual checks.

Goal

Read soil moisture reliably and decide when to water, keeping the plant inside a healthy moisture range.

My Role

Worked across circuit wiring, control code, calibration, and testing to get consistent, repeatable behavior.

Tools

Arduino/C++, embedded systems, soil-moisture sensor, pump control, and circuit design.

Key Features

  • Continuous soil-moisture monitoring
  • Automatic pump activation
  • Calibrated threshold behavior

What I Learned

How noisy sensor readings translate into control decisions, and how calibration and timing affect a hardware system in practice.
