Academic Project

Autonomous Navigation Robot

An autonomous robot built to interpret sensor and camera feedback, navigate a course, avoid obstacles, and report system state during testing.

Overview

This project brought embedded programming, physical hardware, and real-time decision making together in a working mobile robot.

Goal

Move through an arena reliably while responding to obstacles, course boundaries, and changing sensor inputs.

My Role

Contributed to control logic, sensor integration, debugging, testing, and documenting how the robot behaved across design iterations.

Tools

Arduino/C++, embedded sensors, camera feedback, MQTT communication, circuit debugging, and team-based testing.
