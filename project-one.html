Academic Project

Autonomous Navigation Robot

An autonomous robot built to interpret sensor and camera feedback, navigate a course, avoid obstacles, and communicate system state during testing.

Overview

This project focused on bringing together embedded programming, physical hardware, and real-time decision making in a working mobile robot.

Problem or Goal

The goal was to move through an arena reliably while responding to obstacles, course boundaries, and changing sensor inputs.

My Role

I contributed to control logic, sensor integration, debugging, testing, and documenting how the robot behaved during each design iteration.

Tools and Technologies

Arduino/C++, embedded sensors, camera feedback, MQTT communication, circuit debugging, and team-based testing.

Key Features

What I Learned
